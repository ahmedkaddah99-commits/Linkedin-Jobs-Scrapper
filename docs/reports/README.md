## Folder Rules

- New reports should include the date in the filename.
- New reports should include the date in the H1 title.
- New reports should include a `Created date` or `Report date` field near the top.
- Keep source PRDs in their original locations unless a separate migration is planned.
- Add new PRDs, epics, user-story packs, and implementation reports to the catalog in this folder.

## Included Document Types

- PRDs
- User-story collections
- Epic or issue-draft collections
- Strategy reports
- Implementation reports
- Technical specs that guide product or engineering work

## Excluded Document Types

- Dependency documentation under `node_modules`
- Sample CV or template research notes under `test CV` / `test-CV`
- Generated runtime artifacts
