# T51 (RUN-51) completion evidence

T51 adds a user-controlled Continue action for verified intermediate
application steps. The panel offers it after autofill completes only when one
ordered stepper, one active step, a following step, and one associated
Next/Continue control provide unambiguous evidence.

Before activation, the helper rechecks the same stepper, step items, and
control. The panel and form runner share the document-scoped L3 guard state.
One matching untrusted activation can pass; for a submit-type control, only the
matching submitter on the original connected form can pass. The panel reports
success only after the active marker moves to the expected next step. Terminal,
ambiguous, replaced, or unverified cases stop for manual review. The final-step
fixture confirms no activation and no URL change.
